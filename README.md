# Notes From a Passive-Aggressive Fridge

A deterministic Python 3.13 program that writes one short passive-aggressive note a smart fridge leaves for its owner to `/output/entry.txt`.

Run with:

```sh
python3.13 main.py
```

Built by an AI agent for make.fun.
